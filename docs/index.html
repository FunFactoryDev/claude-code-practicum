How it works

  1. Copy the projectThe "Use this template" button on GitHub, or git clone. No dependencies to install.
  2. Do the tasks with ClaudeEach one is about one technique: plan mode, rules, hooks, skills, MCP, unattended runs.
  3. Check with one commandnpm run check tells you what is done, what is not and why, and links to the lesson.

What you need

Node.js 20+ and Claude Code with a Claude subscription or an API key — the only paid part. No access? Take the course in the browser: the simulator practices the same topics with nothing to install and nothing to pay.

Safe for a beginner

The project has no dependencies, hooks, MCP servers or Claude settings — you create all of that yourself. Only what you can see in package.json runs. The check reads files and changes nothing.
